Toybox

Desk toys, a dice tray, animated backgrounds, a drawing layer and extra pages for any web page, with one script tag. Each part's code loads the first time the page uses it; the toys pause when the tab is hidden or they scroll out of view, and open paused when the system asks for reduced motion.

Add it to a page

As an ES module, from wherever this folder is served (every file it loads is found next to the script):

<script type="module" src="https://example.com/toybox/toybox.js"></script>

Or as a classic script: the toys alone, or everything but the 3D dice in one file:

<script src="https://example.com/toybox/toybox.iife.js"></script>
<script src="https://example.com/toybox/toybox-all.iife.js"></script>

An animated background

Behind this page. Its controls sit where the element is (here, at the top of the page); press the name to see the next of six, drag on bare background to stir it, turn on Color mode and scroll the mouse wheel over bare background, or pick a colour on the wheel. Content marked data-solid is not background.

<toy-background></toy-background>   (all six; effects="lines,aurora,stars" picks some, controls="compact|none" shows fewer)

A card with a drawing layer and dice

Draw on the card with the Draw button in the window's lower left corner (its ⋯ menu moves it to another corner; drag its grip to put it anywhere); Show scribbles and Print scribbles are separate. The buttons carry data-roll and roll into the dice tray; click the portrait to open the image editor.

<draw-layer id="card-ink" for="#card"></draw-layer>
<button data-roll="2d6+2" data-roll-label="STR" data-roll-bands="wod">STR +2</button>
<dice-tray id="dice" roll-links save-log></dice-tray>

A thief with a lucky coin that never lands the way she calls it.

The toy drawer

Every toy as a card; opening one shows it in a panel under the cards with Pause, Reset and Close.

<toy-drawer></toy-drawer>

Some toys, in floating windows

Pick toys and their order with toys; panel="floating" makes the drawer a window at the lower left, and each toy opens in a window of its own beside it, several at once. Drag a window by its title bar, resize it from its corner, minimize or close it; each is remembered for this page. At most max-running toys (4 unless set) run at once: the ones used last.

<toy-drawer toys="bubble-wrap,fidget-spinner,pin-art,lava-lamp" panel="floating" theme="dark"></toy-drawer>
drawer.open('bubble-wrap'); drawer.open('fidget-spinner');

One toy, embedded

A <toy-box> shows one toy at the size you give it (320 × 360 px if you give none).

<toy-box toy="newtons-cradle" style="width: 300px; height: 340px"></toy-box>
<toy-box toy="lava-lamp" theme="dark"></toy-box>
<toy-box toy="zen-garden" theme="light"></toy-box>

Notes and drawing pages

Pages kept in this browser and printed one per sheet after the page. Save file writes one JSON file of the pages, the card's scribbles and the tray's log; Open file reads it back.

<toy-pages id="pages"></toy-pages>
